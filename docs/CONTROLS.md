# Field manual

Choose **Start Incident** for the three-stage story or **Stage Practice** to begin at any stage. Start on Easy to learn the patterns; Normal and Lunatic increase the pressure.

## Menu

| Key | Action |
| --- | --- |
| Up / Down | Select an item or practice stage |
| Left / Right | Change difficulty on the main menu |
| Enter | Confirm |
| Esc | Return from practice selection or the field manual |
| M | Toggle sound |
| F11 | Toggle fullscreen |

## Flight

| Key | Action |
| --- | --- |
| Arrow keys / WASD | Move |
| Z / Space | Shoot |
| Shift, held | Move slowly and show the hitbox |
| X | Use a bomb: the shutdown ritual |
| C | Toggle autofire |
| Esc | Pause or resume |
| M | Toggle sound |
| F11 | Toggle fullscreen |

Only the small point at Reimu's center takes a hit. Hold Shift to see it and make precise movements. A close pass beside a bullet earns graze points. Collect **P** items for stronger shots and **+** items for points. Use a bomb to clear danger before you lose a life.

Each boss has three spell patterns. Defeat a spell without taking a hit or using a bomb to capture it. A timeout advances the fight without a capture.

## Dialogue and pause

Press **Z** or **Enter** to advance dialogue; hold **Ctrl** to skip it.

While paused, **Esc** or **Enter** resumes, **R** restarts the run, and **Q** returns to the title. A restart begins a fresh story run or restarts your selected practice stage.

## After a run

At game over, **Enter** continues with the score reset, **R** restarts, and **Esc** returns to the title. After a story or practice clear, **Enter** returns to the title.

Records are stored locally in `records.txt`, inside the platform preference folder returned by `SDL_GetPrefPath("ScarletMesa", "ScarletMesa")`.
